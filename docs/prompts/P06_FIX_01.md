3. Launch ADMIN HTTP review REJECTED cho document cũ. Nó đã qua auth/global/actor recheck và tới owner-lock query. Record waiter backend PID; dùng observer connection của PostgreSQL test xác nhận waiter bị upload PID block trên lock (ví dụ `pg_blocking_pids(waiterPid)` chứa holderPid). Chứng minh review chưa hoàn tất và row upload chưa visible ở observer trước release.
